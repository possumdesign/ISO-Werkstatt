# Portable Tools

Dieser Ordner enthält optionale portable Werkzeuge für das
Windows-11-Lab-Image.

Der Inhalt wird beim Build automatisch nach

C:\ISO-Werkstatt\Tools

kopiert.

## Regeln

- bevorzugt portable / installerfreie Versionen
- keine Tools, die zwingend Systemdienste installieren
- keine Zugangsdaten oder Konfigurationsgeheimnisse
- Lizenzbedingungen der jeweiligen Software beachten

## Aktuell vorgesehen

- CrystalDiskInfo
- CrystalDiskMark
- Sysinternals
