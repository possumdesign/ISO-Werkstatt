# Installationsmedien selbst bereitstellen

Dieses Projekt liefert keine Windows- oder VirtIO-ISOs und keine Windows-Lizenz. Medien selbst über die offiziellen Bezugsquellen herunterladen und ihre jeweiligen Bedingungen beachten:

- [Windows 11 – Microsoft](https://www.microsoft.com/software-download/windows11)
- [Windows 10 – Microsoft](https://www.microsoft.com/software-download/windows10)
- [Windows Server – Microsoft Evaluation Center](https://www.microsoft.com/evalcenter) oder der eigene Microsoft-Lizenzzugang
- [VirtIO-Windows-Treiber – Fedora-Projekt](https://fedorapeople.org/groups/virt/virtio-win/direct-downloads/)

Der Builder verwendet x64-Medien. ISO-Dateien können hier lokal abgelegt oder im Builder von einem anderen Speicherort ausgewählt werden. Sie werden nicht in Git aufgenommen. VirtIO ist nur nötig, wenn Treiberintegration oder QEMU Guest Agent aktiviert sind.

No installation media or Windows license is included. Obtain Windows from Microsoft and VirtIO from its publisher. Local downloads and generated ISOs are not part of the source release.
